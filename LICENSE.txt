AVISOS DE TERCEIROS / THIRD-PARTY NOTICES

Este software implementa o protocolo de comunicação da família de impressoras
conhecida como "CAT Printer" (GB0x, GT01, SC03h, MX0x, YT01, PD01, MXTP).

Os fatos de protocolo (UUIDs GATT, códigos de comando, formato de frame,
algoritmo de checksum e ordem da sequência de impressão) foram obtidos e
verificados a partir das seguintes implementações de código aberto:

1. NaitLee/Cat-Printer — https://github.com/NaitLee/Cat-Printer
   Os módulos printer_lib/commander.py e printer_lib/models.py são publicados
   sob CC0-1.0 (domínio público). O restante do repositório é GPL-3.0.
   Nenhum arquivo desse projeto foi copiado para este software.

2. bitbank2/Thermal_Printer — https://github.com/bitbank2/Thermal_Printer
   Licenciado sob Apache License 2.0. Usado como confirmação independente dos
   UUIDs, dos frames fixos, do espelhamento de bits e do CRC.
   Nenhum arquivo desse projeto foi copiado para este software.

A implementação em C# deste projeto é original.

Componentes de plataforma utilizados (não redistribuídos como código-fonte):
- .NET 8 e Windows Desktop Runtime (MIT, Microsoft)
- System.Drawing.Common (MIT, .NET Foundation)
- APIs Windows.Devices.Bluetooth / WinRT (Microsoft)
